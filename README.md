# 🎮 Tic Tac Toe Game – Interactive Web Application

### SkillCraft Technology – Web Development Internship | Task 3

An interactive and visually appealing **Tic Tac Toe Game** developed using HTML, CSS, and JavaScript. The application allows users to play against another player or challenge a computer opponent through a simple and engaging interface.

## 📌 Project Overview

This project is a browser-based Tic Tac Toe game designed to demonstrate frontend web development and JavaScript programming concepts.

The game features a classic 3×3 grid where two players take turns marking their respective symbols (X and O). It includes two different playing modes: Player vs Player and Player vs Computer.

The application automatically checks winning combinations, identifies draws and updates the game status in real time.

## ✨ Key Features

### 1. Two Game Modes
- **Player vs Player:** Allows two players to compete on the same device.
- **Player vs Computer:** Allows a single player to play against a computer opponent.

### 2. Interactive 3×3 Game Board
- Classic Tic Tac Toe gameplay.
- Interactive cells for placing X and O.
- Visual hover effects.

### 3. Automatic Winner Detection
- Checks all eight possible winning combinations.
- Identifies the winning player.

### 4. Draw Detection
- Automatically identifies when all cells are filled without a winner.

### 5. Computer Opponent

### 6. Restart Functionality
- Restarts the game instantly.
- Clears all previously selected cells.
- Resets the current player and game status.

### 7. Modern UI Design
- Gradient background.

## ⚙️ How the Game Works

1. Launch the game in a web browser.
2. Select a playing mode.
3. Player X makes the first move.
4. Players take turns selecting empty cells.
5. In computer mode, the computer automatically plays as O.
6. JavaScript checks all eight winning combinations after each move.
7. If a player completes a winning combination, the game displays a victory message.
8. If all nine cells are filled without a winner, the game declares a draw.
9. Click the Restart button to start a new game.

## 🏆 Winning Combinations

The game checks eight possible winning combinations:

- Three horizontal rows.
- Three vertical columns.
- Two diagonal combinations.

A player wins when three identical symbols appear in any one of these combinations.
